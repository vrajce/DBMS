# Relation Model

1) Relation model ussed to model the data into relation/table.
2) This can be done by RDBMS langugages like oracle , sql ,...
3) Relation model uses the collection of tables to represent data and relationship between tables.
4) Each table has multiple columns and each have unique names.
5) Table is also known as relation.
6) now each column has same type of data in that particular column(same datatype).
7) Relational model
